🔧 Daemon Architecture
Python · Win32
01 Lightweight Python agent installs as a Windows Service — no workflow change for chemist. Reads local Marg/Tally SQL db via ODBC.
02 Incremental sync via row-level change detection on item_master and batch_stock tables. Only delta pushed — not full dumps.
03 All payloads AES-256 encrypted in transit. Cloud endpoint is tenant-isolated. Agent holds only a rotating JWT — no admin credentials stored.
04 Schema normalisation layer maps Marg / GoFrugal / Tally / custom CSV formats to unified PharmaBridge inventory schema before cloud write.

🏗️ Multi-Tenant K8s
Namespace Isolation
Each pharmacy tenant runs in an isolated K8s namespace. Network policies block cross-tenant traffic at the pod level.
Event-Driven Sync
Daemon pushes → Kafka topic → consumer group per tenant → writes to isolated PostgreSQL schema. No shared tables.
ONDC BPP Adapter
Stateless BPP pods scaled via HPA. Inventory cache in Redis per tenant. TTL: 90 seconds for stock levels.
