Review Documentation Standard

Every review document must separate facts from assumptions.

Format

Verified Facts

Information directly observed from:

- Commands
- Logs
- API responses
- Database queries
- Source code

Evidence

Exact output, command, log, or file reference.

Assessment

Interpretation of the evidence.

Hypotheses

Possible explanations that have not been verified.

Decisions

Approved project decisions.

Next Actions

Follow-up validation or engineering work.
